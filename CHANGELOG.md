# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Added GNU/Hurd support (uses `mmap` without `MAP_STACK`).

### Fixed

- Detected stack overflows triggered by writes to the Windows guard page and
  reported `Error::StackErr` instead of crashing the process.
- Avoided `MaybeUninit::assume_init` undefined behavior in the Unix `sigaction`
  and `getrlimit` paths.
- The Unix `sigaction` test no longer re-executes the test binary as a
  subprocess.

### Removed

- Removed an unused Travis CI script.

## [0.8.12] - 2026-11-05

### Added

- Expanded tests for cancellation, panic unwinding, stack overflow, allocation
  failure, and generator re-initialization.

### Changed

- Raised the minimum supported Rust version from 1.73 to 1.95.
- Updated the generated Windows bindings for `windows-bindgen` 0.100; signal
  and exception handlers no longer write to stderr.
- CI now tests macOS aarch64 and Android x86_64 and performs build-only checks
  for the Fuchsia targets.
- Replaced `cfg_if` with `cfg_select` and used a typestate for uninitialized
  stack boxes.
- Clarified documentation for `Send`, `Scope`, cancellation, stack usage,
  `from_raw` safety, and `yield_` error handling.

### Fixed

- Stack handling now uses the running context's stack guard for overflow
  checks, releases the stack mapping when guard setup fails, tracks stack-box
  offsets to enforce LIFO drop order, and no longer re-raises `StackErr` when
  dropping an overflowed generator.
- Reserved headroom for the generator bootstrap frame and the ELFv2 linkage area
  on ppc64le.
- Cleared input/output state and stored panic data when re-initializing a
  generator or coroutine, reset I/O state before the scope borrows it, and kept
  the generator marked done if `init_code` allocation fails.
- Cancelled coroutines at the yield point like generators; a swallowed cancel
  no longer leaves the coroutine parked.
- Made the generator input type invariant and made `Drop` panic-safe.

## [0.8.11] - 2026-10-14

### Added

- 32-bit x86 (i686 Linux) support, including CI coverage.

### Changed

- `DEFAULT_STACK_SIZE` and stack sizes are documented in `usize` words instead
  of bytes; the actual default stack size is unchanged.

## [0.8.10] - 2026-09-17

### Added

- s390x Linux support.

### Changed

- Removed `compiler_fence`.

### Fixed

- Fixed fat-LTO link failures on `x86_64-pc-windows-msvc`.
- Fixed an optimization issue with recent nightly compilers.

## [0.8.9] - 2026-06-01

### Added

- Windows on aarch64 (`aarch64-pc-windows-msvc`).
- watchOS and tvOS targets.

### Changed

- Documented Windows support in the README and added Windows aarch64 to CI.

## [0.8.8] - 2025-12-17

### Changed

- Replaced the `windows` crate dependency with checked-in bindings generated by
  `windows-bindgen`.
- Upgraded `windows-bindgen` and adopted the `windows` crate's `GetLastError()`
  behavior and `windows-result` error handling.

### Fixed

- Made thread-local access robust on macOS and Windows with Rust 1.90+.
- Fixed warnings introduced by Rust 1.91 nightly.

## [0.8.7] - 2025-08-21

### Changed

- Re-release of the yanked 0.8.6. Fixed the debug/release condition guarding the
  macOS/Windows workaround added in 0.8.6.

## [0.8.6] - 2025-08-21

**Yanked. Use 0.8.7 instead.**

### Changed

- Set the `windows` dependency range to 0.58–0.61 after reverting an update.
- Refined the per-thread context and added a workaround for a thread-local bug
  on macOS and Windows with Rust 1.89+.

### Fixed

- Attempted fixes for macOS test failures.

## [0.8.5] - 2025-05-13

### Added

- powerpc64le Linux support.

### Changed

- Updated the `windows` dependency.
- Marked root context initialization as cold.
- Temporarily disabled Android x86_64 CI.

## [0.8.4] - 2024-12-05

### Added

- aarch64 iOS support.
- loongarch64 Linux CI coverage.

### Changed

- Relaxed the minimum supported Rust version from 1.77 to 1.73.

### Fixed

- Fixed build errors on the MSRV.
- Fixed a Unix `sigaction` clippy warning.

## [0.8.3] - 2024-09-01

### Added

- Minimum supported Rust version: 1.77.
- `InitFn` definition for loongarch64.

### Changed

- Refined root context thread-local storage.
- Temporarily removed Android x86_64 from the supported platforms list and CI.
- Enabled stable-compiler tests in CI.

## [0.8.2] - 2024-07-25

### Changed

- Updated the `windows` dependency to 0.56.
- Internal refactoring and lint cleanups; no user-facing API changes.

## [0.8.1] - 2024-03-06

### Changed

- Raised the minimum `libc` version from 0.2 to 0.2.100.
- Updated the README for the 0.8 series.

## [0.8.0] - 2024-03-04

### Changed

- Dependency update only (`windows` 0.54); no source or API changes.

## [0.7.6] - 2024-02-27

### Added

- Stack-overflow detection that reports `Error::StackErr` instead of aborting
  the process.
- LoongArch64, armv7, and riscv64 support.
- More targets in CI.

### Changed

- Switched to `global_asm!` and the C ABI for `InitFn`.
- Added the `'scope` lifetime to `Scope`; `yield_` is now only available when
  the generator's captured data is `'static`, with `yield_unsafe` for other
  cases.
- Updated `windows-sys` to 0.53.

### Fixed

- Fixed `yield_from_unsafe` documentation.

## [0.7.5] - 2023-06-24

### Added

- Fuchsia support.
- macOS aarch64 support.
- `DEFAULT_STACK_SIZE` is now publicly exported.

## [0.7.4] - 2023-04-21

### Changed

- Improved aarch64 context-switching performance.
- Used `std::any::type_name` for clearer type errors.

### Fixed

- Fixed a Windows compile issue.

## [0.7.3] - 2023-02-23

### Changed

- Used `jump` instead of `ret` when switching contexts on x86.
- Updated Windows dependencies.

### Fixed

- Fixed Windows assembly.

## [0.7.2] - 2022-12-07

### Changed

- Unified and tuned CPU prefetching across platforms.
- Updated the `windows` dependency to 0.39.

## [0.7.1] - 2022-07-17

### Added

- GitHub Actions CI.

### Changed

- Migrated from `winapi` to the `windows` crate.
- Used `panic_any`.
- Preserved floating-point registers on aarch64.

### Fixed

- Fixed an incorrect `assume_init` in `done` (#34).
- Panic filtering now excludes `Done` and `Cancel`.
- Fixed a release-mode bug in the `cd` example.

## [0.7.0] - 2021-03-30

### Added

- Public `LocalGenerator` type for generators that are not `Send`.

### Changed

- `Generator::cancel` is now safe to call.
- Static generators are `Send` only when both the message type and output type
  are `Send`; generator closures are required to be `Send`.

### Fixed

- Fixed code reordering in release builds.

## [0.6.25] - 2021-03-23

### Fixed

- Fixed aarch64 release optimization, stack initialization, and stack-unwinding
  issues.

## [0.6.24] - 2021-02-21

### Added

- aarch64 support on Linux and macOS.

### Changed

- Replaced `rustc_version` with `rustversion`.
- Fixed 2021-edition panic warnings.
- Removed the AppVeyor build.

## [0.6.23] - 2020-10-21

### Changed

- Downgraded the "generator not fully consumed" warning to a trace message.
- Removed the `cold` attribute.

## [0.6.22] - 2020-09-07

### Fixed

- Removed the naked-function feature to fix nightly builds (#24).

## [0.6.21] - 2020-06-19

### Added

- `into_raw`/`from_raw` for generators and stack boxes.

### Changed

- Allocated generator functions and stack boxes in stack memory.
- Hid `GeneratorImpl`.
- Removed unnecessary register save/restore.
- Migrated to `llvm_asm!` (later replaced).

## [0.6.20] - 2020-02-04

### Added

- illumos/Solaris support.

### Changed

- Build now fails with a clear error when the target architecture is
  unsupported.
- Replaced deprecated `Error::description` and `Error::cause`.

## [0.6.19] - 2019-10-24

### Added

- `Generator::get_para` API.

### Removed

- Removed the stack tracking flag.

## [0.6.18] - 2019-09-05

### Changed

- Deprecated non-scoped generator APIs (#14); `Gn::new_opt` remains available.
- Added a context check for `done` (#13).

### Fixed

- Removed undefined behavior in the generator implementation.

## [0.6.17] - 2019-07-31

### Changed

- Allowed warnings for the latest nightly compiler.

## [0.6.16] - 2019-07-08

### Fixed

- Replaced deprecated `mem::uninitialized()`.

## [0.6.15] - 2019-07-08

### Changed

- Optimized coroutine parameter get/set and added more cold-path
  optimizations.
- Renamed the `sys` module file.

## [0.6.14] - 2019-06-12

### Changed

- Used guarded stacks (#12).
- Updated to Rust 2018 edition.

## [0.6.13] - 2019-04-13

### Fixed

- Call `mem::forget` on the `Done` dummy value (#11).

## [0.6.12] - 2019-02-20

### Changed

- Removed the `get_scope` API (#9).

### Fixed

- Fixed the assembly bootstrap stack issue (#8).
- Fixed macOS release-mode assembly.

## [0.6.11] - 2019-02-15

### Added

- `co_set_para` API.
- Windows release-build support.
- Release-mode tests.

## [0.6.10] - 2018-07-09

### Changed

- Used `Vec<T>` as the default raw-buffer allocator.

## [0.6.9] - 2018-05-17

### Changed

- No user-facing changes.

## [0.6.8] - 2018-05-17

### Fixed

- Fixed nightly register swapping on Unix.
- Worked around naked-function problems in rustc 1.27 (#6).
- Fixed rustc 1.27.0-nightly debug builds (#6).

## [0.6.6] - 2018-03-02

### Changed

- Sped up thread-local storage access.
- Restricted `#[thread_local]` to nightly builds.
- Removed the unused `get_ref_ptr`.

## [0.6.5] - 2018-01-03

### Fixed

- Saved all XMM registers on Windows x86_64.

## [0.6.4] - 2018-01-03

### Fixed

- Saved additional XMM registers on Windows.

## [0.6.3] - 2017-12-24

### Changed

- Relicensed from LGPL-2.1 to MIT/Apache-2.0.
- Updated the crate description.

## [0.6.1] - 2017-10-11

### Changed

- Removed the nightly-only requirement from the README.
- Replaced the `gcc` build dependency with `cc`.
- Updated the README license section.

## [0.6.0] - 2017-09-17

### Added

- Hand-written assembly supporting stable and nightly Rust on x86_64 Linux,
  macOS, and Windows (GNU and MSVC).
- Scoped generators, coroutine support, cancellation, panic propagation,
  per-context local data, and the `Error` type (carried over from the 0.2–0.5
  line).

### Changed

- Removed nightly-only features such as `fnbox`.
- Used `Vec<T>` as the raw-buffer allocator on stable.

## [0.5.1] - 2017-08-05

### Added

- Scoped generators (`Scope`) and the `done` helper.
- Generator cancellation and panic propagation.
- `yield_with`, `yield_from`, and coroutine (`co_*`) helpers.
- Per-context local data and the `Error` type.
- Windows support.

### Changed

- Nightly Rust required.

## [0.2.0] - 2015-11-08

### Added

- Initial release: stackful generators with `Gn`, `yield_with`, `get_yield`, and
  `yield_from`.
- x86_64 Unix support (nightly Rust).
